One sentence explaining the modern internet to a traveler from 1800, using only words they would already know: it is one road joining every post office, library, and market square on earth, where anyone may send the words of a letter, book, or song to any town and hear an answer back in the blink of an eye. Running main.py writes the sentence to /output/entry.txt.

## Run it

```sh
python3 main.py
```
